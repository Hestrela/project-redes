Detecção Autônoma de Anomalias de Tráfego Web por Desvio Geográfico e Volumétrico Utilizando Aprendizado de Máquina

Estudo comparativo entre Árvores de Decisão, Random Forest e XGBoost na identificação de ataques distribuídos (DDoS/Botnets) a partir de surtos atípicos de acessos via GeoIP.

Por: Vinicius O., Giulia A., Heitor E., Gabriel R., Miguel S.
Publicado em: 08/09/2026
Última Revisão: 18/10/2026

1. Introdução & Problemática

Sistemas tradicionais de Web Analytics (como Google Analytics e logs estáticos de Nginx) concentram-se em apresentar gráficos consolidados sobre os principais países que acessam uma aplicação web. Contudo, relatórios estáticos não conseguem reagir a ameaças de cibersegurança dinâmicas.

A Problemática Central: Quando uma região geográfica com histórico insignificante de requisições (ex.: 0.1% do tráfego habitual) apresenta um aumento exponencial e repentino em um intervalo de poucos minutos, o sistema está enfrentando um surto de tráfego legítimo por viralização ou um ataque volumétrico distribuído (Botnet/DDoS)?

Neste estudo, avaliamos comparativamente algoritmos de Aprendizado de Máquina alimentados por geolocalização de IP (GeoIP) e métricas de desvio padrão relativo (Z-score por país e taxa de erro HTTP 4xx/5xx) para determinar qual modelo se destaca na classificação do tráfego entre os estados NORMAL, SUSPEITO e ATAQUE.

3. Modelos Avaliados no Experimento

1 / 3

3.1. Árvore de Decisão (Decision Tree)

Modelo não-paramétrico que particiona o espaço de atributos por regras lógicas claras. Destaca-se pela capacidade de conversão direta em regras de firewall (WAF) com tempo de resposta quase instantâneo.

3.2. Random Forest (Bagging)

Combina múltiplas árvores de decisão treinadas em paralelo em subconjuntos de atributos (país, ASN, taxa de erros). Oferece alta resiliência a falsos positivos causados por tráfego sazonal.

3.3. XGBoost (Gradient Boosting)

Algoritmo de gradiente otimizado que ajusta sequencialmente os erros dos modelos anteriores. Busca obter a maior acurácia possível em datasets de altíssima volumetria de logs.

5. Pipeline Python & Processamento GeoIP

Abaixo apresenta-se a estrutura em Python para extração de atributos e comparação entre os algoritmos de aprendizado:

benchmark_modelos.py Python 3.10 | scikit-learn & xgboost 
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from xgboost import XGBClassifier
from sklearn.metrics import classification_report

FEATURES = ["zscore_volume_pais", "ratio_erro_http", "requisicoes_por_minuto", "entropia_asn"]

# Dicionário com os 3 candidatos a avaliação
modelos = {
    "DecisionTree": DecisionTreeClassifier(max_depth=4, criterion="entropy", random_state=42),
    "RandomForest": RandomForestClassifier(n_estimators=100, random_state=42),
    "XGBoost": XGBClassifier(n_estimators=100, learning_rate=0.1, random_state=42)
}

# Execução do benchmark comparativo
for nome, model in modelos.items():
    model.fit(X_treino[FEATURES], y_treino)
    y_pred = model.predict(X_val[FEATURES])
    print(f"=== Modelo: {nome} ===")
    print(classification_report(y_val, y_pred, digits=4))

6. Resultados & Métricas Comparativas

A avaliação experimental no conjunto de validação com dados de log rotulados apresentou os seguintes resultados:

7. Avaliação e Escolha do Modelo

A escolha do modelo ideal depende das restrições de infraestrutura do sistema de monitoramento:

• Se o objetivo for mitigação em tempo real na Borda (Edge / WAF): A Árvore de Decisão destaca-se devido à latência de 0.03ms e facilidade de tradução direta das regras para firewalls.

• Se o objetivo for máxima acurácia em SIEM centralizado: O XGBoost e a Random Forest são superiores, reduzindo falsos positivos ao custo de maior consumo computacional.
